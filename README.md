## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.

## Local checks and Takt

Use Node 24 (nvm use), Python 3.11+ and npm ci once after checkout.
Run ./scripts/check.sh quick for lint, route types, TypeScript and tests,
and ./scripts/check.sh verify to include the production build.

[Takt workflow](docs/takt-workflow.md) covers optional pre-push checks, issue-driven
delivery, automatic image versions and elapsed time in In progress and Review.
Automatic delivery stays disabled until the team reviews and activates it.

[Courier deliveries](docs/courier-deliveries.md) documents the courier screen,
API dependency, error handling and focused UI checks.

[Runtime capabilities](docs/feature-flags.md) documents the feature flag provider,
backend contract, failure handling and future product flag enrollment.
